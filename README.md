# Google Play Store Data Analysis | Power BI

## Project Overview

This project presents an interactive Power BI dashboard built to analyze Google Play Store application data. The dashboard provides insights into app categories, ratings, installations, reviews, and application trends.

It includes an Overview dashboard for understanding overall app performance and a Details dashboard for exploring individual applications.

## Dashboard Screenshots

### 1. Overview Dashboard

This dashboard provides a summary of app performance using KPI cards, charts, and tables.

![Google Play Store Overview Dashboard](googleplaystore%202.jpg)

### 2. Details Dashboard

This dashboard displays application-level information, including app name, category, version, size, year, number of installs, and reviews.

![Google Play Store Details Dashboard](googleplaystore%201.jpg)

## Key Features

- KPI cards showing total apps, average rating, installs, and maximum reviews.
- Category-wise analysis of app installations and reviews.
- Comparison of app counts by category and app type.
- Year-wise trend analysis.
- Interactive filters for app type, year, and other available fields.
- Detailed application-level information.

## Tools Used

- Microsoft Power BI
- Data Visualization
- Interactive Dashboards
